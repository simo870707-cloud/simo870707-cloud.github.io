Install on Android
ANDROID · APK · v1.0.0

Android flags every app installed outside the Play Store. The “file might be harmful” prompt is expected — tap Download anyway.

How to install
1. Tap Install on Android above (on your phone).
2. Chrome may say “file might be harmful” — normal for apps outside the Play Store. Tap Download anyway.
3. Open the downloaded file. If Android warns about an unknown source, tap Settings → allow from this source, then Install.
4. If Play Protect says “blocked to protect your device”, tap More details → Install anyway.
5. Open 1 HOUR and read before the hour passes.
